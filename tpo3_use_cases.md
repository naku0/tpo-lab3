# Тестирование Xing.com

## Акторы

| Актор                     | Описание                                                                        |
| ------------------------- | ------------------------------------------------------------------------------- |
| **Гость (Guest)**         | Неавторизованный пользователь, может просматривать ограниченный контент         |
| **Пользователь (Member)** | Авторизованный пользователь с полным доступом к функциям                        |
| **Рекрутер (Recruiter)**  | Пользователь с расширенными правами для публикации вакансий и поиска кандидатов |
| **Администратор**         | Системный администратор с правами модерации                                     |

## Прецеденты использования (Use Cases)

### UC-01: Регистрация нового пользователя

Актор: Гость

Предусловие: Пользователь не зарегистрирован на xing.com

Триггер: Пользователь нажимает "Join now" / "Jetzt registrieren"

Основной поток:

- Гость открывает страницу регистрации
- Вводит email-адрес
- Создает пароль
- Подтверждает согласие с условиями использования
- Нажимает кнопку регистрации
- Система отправляет письмо с подтверждением
- Пользователь переходит по ссылке из письма
- Аккаунт активирован

Альтернативные потоки:

1. Email уже зарегистрирован → показать сообщение об ошибке
1. Невалидный email → валидация поля
1. Слабый пароль → требование усилить пароль
1. Регистрация через LinkedIn/Google → OAuth-авторизация

Постусловие: Создан новый аккаунт, пользователь авторизован

### UC-02: Авторизация пользователя

Актор: Пользователь

Предусловие: Пользователь зарегистрирован

Триггер: Пользователь нажимает "Log in" / "Anmelden"

Основной поток:

- Пользователь открывает страницу входа
- Вводит email и пароль
- Нажимает "Log in"
- Система валидирует учетные данные
- Пользователь перенаправлен на ленту активности

Альтернативные потоки:

1. Неверный пароль → сообщение об ошибке, счетчик попыток
1. Несуществующий email → предложение регистрации
1. Забытый пароль → переход к UC-03
1. Двухфакторная аутентификация → ввод кода

Постусловие: Пользователь авторизован, создана сессия

### UC-03: Восстановление пароля

Актор: Пользователь

Предусловие: Пользователь забыл пароль

Основной поток:

- Пользователь нажимает "Forgot password?"
- Вводит email
- Система отправляет ссылку для сброса
- Пользователь переходит по ссылке
- Вводит новый пароль
- Подтверждает изменение

### UC-04: Управление профилем

Актор: Пользователь

Предусловие: Пользователь авторизован

Под-прецеденты:

- UC-04.1: Редактирование личной информации
  - Изменение имени, фамилии
  - Загрузка фото профиля
  - Добавление заголовка (headline)
  - Редактирование местоположения

- UC-04.2: Управление опытом работы
  - Добавление новой позиции (компания, должность, период)
  - Редактирование существующей позиции
  - Удаление позиции

- UC-04.3: Управление образованием
  - Добавление учебного заведения
  - Указание степени и специальности
  - Указание периода обучения

- UC-04.4: Управление навыками
  - Добавление навыков (skills)
  - Удаление навыков
  - Подтверждение навыков другими пользователями (endorsements)

- UC-04.5: Управление языками
  - Добавление языков
  - Указание уровня владения

### UC-05: Поиск

Актор: Пользователь / Гость

Под-прецеденты:

- UC-05.1: Поиск людей
  - Ввод имени/фамилии в поисковую строку
  - Применение фильтров (местоположение, компания, отрасль)
  - Просмотр результатов
  - Переход в профиль найденного пользователя

- UC-05.2: Поиск вакансий
  - Ввод ключевых слов
  - Фильтрация по: местоположению, отрасли, типу занятости, зарплате
  - Сортировка результатов
  - Сохранение поиска

- UC-05.3: Поиск компаний
  - Поиск по названию компании
  - Фильтрация по отрасли, размеру, местоположению

### UC-06: Нетворкинг (Управление контактами)

Актор: Пользователь

Под-прецеденты:

- UC-06.1: Отправка запроса на добавление в контакты
  - Просмотр профиля пользователя
  - Нажатие "Add contact" / "Kontakt hinzufügen"
  - Добавление персонального сообщения (опционально)
  - Отправка запроса

- UC-06.2: Принятие/отклонение запроса
  - Просмотр входящих запросов
  - Принятие запроса → контакты связаны
  - Отклонение запроса
  - Блокировка пользователя

- UC-06.3: Управление существующими контактами
  - Просмотр списка контактов
  - Удаление контакта
  - Экспорт контактов

### UC-07: Обмен сообщениями

Актор: Пользователь

Под-прецеденты:

- UC-07.1: Отправка сообщения
  - Открытие диалога с контактом
  - Набор текста сообщения
  - Отправка (Enter или кнопка)
  - Прикрепление файлов (опционально)

- UC-07.2: Управление сообщениями
  - Просмотр списка диалогов
  - Поиск по сообщениям
  - Архивирование диалога
  - Удаление сообщения
  - Пометка как прочитанное/непрочитанное

### UC-08: Управление вакансиями (для рекрутеров)

Актор: Рекрутер

Под-прецеденты:

- UC-08.1: Публикация вакансии
  - Создание новой вакансии
  - Заполнение: название, описание, требования, зарплата, местоположение
  - Публикация вакансии
  - Управление статусом (активна/закрыта)

- UC-08.2: Просмотр откликов
  - Список откликнувшихся кандидатов
  - Просмотр профилей кандидатов
  - Изменение статуса отклика (новый, в рассмотрении, отклонен, принят)

### UC-09: Подача заявки на вакансию

Актор: Пользователь

Основной поток:

- Поиск вакансии (UC-05.2)
- Просмотр деталей вакансии
- Нажатие "Apply now" / "Jetzt bewerben"
- Проверка/редактирование сопроводительного письма
- Прикрепление резюме (если требуется)
- Подтверждение отправки
- Получение подтверждения

### UC-10: Управление лентой активности

Актор: Пользователь

Под-прецеденты:

- UC-10.1: Просмотр ленты
  - Просмотр постов контактов
  - Просмотр рекомендуемых постов
  - Бесконечная прокрутка (infinite scroll)

- UC-10.2: Взаимодействие с постами
  - Лайк поста
  - Комментарий к посту
  - Репост/поделиться
  - Сохранение поста

- UC-10.3: Создание поста
  - Написание текста
  - Прикрепление изображения/ссылки
  - Выбор видимости (все/только контакты)
  - Публикация

### UC-11: Управление настройками аккаунта

Актор: Пользователь

Основной поток:

- Изменение email-адреса
- Изменение пароля
- Настройка приватности (видимость профиля)
- Настройка уведомлений
- Удаление аккаунта
- Экспорт данных (GDPR)

### UC-12: Создание и управление CV (Lebenslauf)

Актор: Пользователь

Предусловие: Пользователь авторизован

Под-прецеденты:

- UC-12.1: Создание CV с нуля
  - Выбор шаблона резюме
  - Автоматический импорт данных из профиля XING
  - Ручное заполнение разделов (данные, опыт, образование, навыки)
  - Предпросмотр резюме
- UC-12.2: Редактирование CV
  - Изменение структуры разделов
  - Добавление/удаление блоков
  - Изменение порядка разделов
  - Редактирование текста в каждом блоке
- UC-12.3: Управление шаблонами оформления
  - Выбор цветовой схемы
  - Выбор шрифта
  - Настройка макета (одна/две колонки)
  - Загрузка фото в резюме
- UC-12.4: Экспорт CV
  - Скачивание в PDF
  - Скачивание в Word (.docx)
  - Выбор языка резюме (DE/EN)
  - Настройка видимости (публичное/приватное)
- UC-12.5: Управление версиями CV
  - Создание нескольких версий резюме
  - Дублирование существующего CV
  - Удаление версии
  - Переименование версии
  - Установка версии по умолчанию
- UC-12.6: Публикация CV
  - Сделать CV видимым для рекрутеров
  - Скрыть CV от текущего работодателя
  - Добавить сопроводительное письмо по умолчанию

### UC-13: Группы и сообщества

Актор: Пользователь

Предусловие: Пользователь авторизован

Под-прецеденты:

- UC-13.1: Поиск и просмотр групп
  - Поиск групп по тематике
  - Просмотр списка популярных групп
  - Просмотр описания и правил группы
  - Просмотр списка участников группы
- UC-13.2: Вступление в группу
  - Нажатие "Join group"
  - Ответ на вопросы для вступления (если требуется)
  - Ожидание одобрения модератора (для закрытых групп)
  - Получение доступа к контенту группы
- UC-13.3: Взаимодействие в группе
  - Просмотр постов группы
  - Публикация поста в группе
  - Комментирование постов
  - Лайк постов
  - Поиск по постам группы
- UC-13.4: Управление группой (для модераторов)
  - Одобрение/отклонение запросов на вступление
  - Удаление постов
  - Блокировка участников
  - Редактирование правил группы
  - Назначение модераторов
- UC-13.5: Выход из группы
  - Нажатие "Leave group"
  - Подтверждение выхода
  - Удаление из списка участников

### UC-14: Premium-подписка и платные функции

Актор: Пользователь

Предусловие: Пользователь авторизован

Под-прецеденты:

- UC-14.1: Просмотр тарифов Premium
  - Сравнение тарифов (Basic/Premium/Business)
  - Просмотр включённых функций
  - Просмотр стоимости подписки
- UC-14.2: Оформление подписки
  - Выбор тарифа
  - Выбор периода (месяц/год)
  - Ввод платёжных данных
  - Подтверждение оплаты
  - Активация Premium-функций
- UC-14.3: Управление подпиской
  - Просмотр текущего тарифа
  - Изменение тарифа (upgrade/downgrade)
  - Обновление платёжных данных
  - Просмотр истории платежей
  - Скачивание счетов (invoice)
- UC-14.4: Отмена подписки
  - Нажатие "Cancel subscription"
  - Указание причины отмены
  - Подтверждение отмены
  - Сохранение доступа до конца оплаченного периода
- UC-14.5: Использование Premium-функций
  - Отправка InMail (сообщения не-контактам)
  - Просмотр полного списка посетителей профиля (без анонимов)
  - Расширенный поиск с дополнительными фильтрами
  - Сравнение профилей с конкурентами
  - Приоритетное отображение в поиске рекрутеров
